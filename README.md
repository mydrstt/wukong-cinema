# Wukong Cinema

Windows 10/11용 손오공 대기 화면입니다. 평소 바탕화면에는 손오공이 보이고, 5분 동안 입력이 없거나 `Ctrl + Alt + G`를 누르면 주변 배경만 부드럽게 흐려지고 어두워지며 살짝 확대됩니다. 키보드·마우스·터치패드를 사용하면 원래 바탕화면으로 돌아옵니다. 다른 프로그램 창 위에 손오공을 상시 표시하지는 않습니다.

![16:10 화면 미리보기](screenshot.png)

## 설치

GitHub에서 ZIP을 **다운로드만 해서는** 배경화면이 바뀌지 않습니다.

1. **Code → Download ZIP**으로 받아 한 폴더에 압축을 풉니다. 파일을 ZIP 안에서 바로 실행하지 마세요.
2. `Install-Autostart.cmd`를 실행합니다. 현재 배경화면의 경로와 배치 설정을 백업하고, 이 컴퓨터의 주 모니터 크기에 맞는 새 배경화면을 만든 뒤 Windows에 적용합니다. 동시에 로그인·잠금 해제 시 자동 실행을 등록하고 바로 백그라운드 실행을 시작합니다. 관리자 권한은 필요하지 않습니다.
3. 압축을 푼 폴더는 그대로 둡니다. 자동 실행이 그 폴더의 EXE와 이미지를 사용합니다. 폴더를 옮기거나 새 버전을 받으면 새 폴더에서 `Install-Autostart.cmd`를 다시 실행하세요.

자동 실행 없이 이번 로그인에서만 사용하려면 `Start-WukongIdleScreen.cmd`를 실행하세요. 이 경우에도 배경화면은 적용되며, 앱만 다음 로그인에 자동 시작되지 않습니다.

`Ctrl + Alt + G`는 대기 화면을 바로 켜거나 끕니다. `Ctrl + Alt + Shift + G` 또는 `Stop-WukongIdleScreen.cmd`는 현재 실행을 종료합니다. **자동 실행을 해제하고 이전 배경화면으로 복구**하려면 `Remove-Autostart.cmd`를 실행하세요. 이후 사용자가 배경화면을 직접 바꿨다면 그 변경은 덮어쓰지 않습니다. 이전 배경화면 파일을 삭제한 경우에는 자동 복구할 수 없습니다.

Windows의 **화면 끄기/절전** 시간은 별도 설정입니다. 대기 화면을 계속 보려면 그 시간을 5분보다 길게 하거나 끄세요.

## 화면과 파일

프로그램은 주 모니터의 해상도에 맞춰 평소 바탕화면을 만들고, 대기 화면도 같은 배경·손오공 이미지로 그립니다. 그래서 전환할 때 인물이 갑자기 다른 그림으로 바뀌는 느낌을 줄였습니다. 16:9·16:10·3:2·세로 화면에서 중앙 인물을 우선해 채우며, 울트라와이드 대기 화면은 양옆을 흐린 배경으로 확장합니다. 보조 모니터의 Windows 바탕화면 배치는 주 모니터와 다를 수 있습니다.

- `WukongCinema.exe`: 실행 파일
- `landscape-clean.png`, `wukong-original-upscaled.png`: 실행에 필요한 배경·손오공 이미지
- `Cinema.cs`, `Build.ps1`: 소스와 빌드 스크립트
- `Set-Wallpaper.ps1`: 바탕화면 적용과 기존 배경 복원
- `original-wallpaper.jpg`: 참고용 원본 그림. 실행에는 사용하지 않습니다.

소스를 수정한 뒤 다시 빌드하려면 실행 중인 앱을 종료하고 PowerShell에서 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1`을 실행하세요. 이 앱은 로컬에서만 작동하며 네트워크 연결이나 계정을 요구하지 않습니다. 이미지의 사용·재배포 권한은 코드 라이선스와 별도로 확인하세요.
